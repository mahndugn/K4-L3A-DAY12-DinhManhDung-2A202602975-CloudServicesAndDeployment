# Minh chứng CloudOps Assistant

Sau khi chạy hoặc deploy thật, chụp:

- dashboard.png: service cloud (che giá trị secret).
- health.png: /health trả service cloudops-assistant.
- ready.png: /ready xác nhận Redis hoạt động.
- ask.png: câu hỏi Docker multi-stage và câu trả lời trong /docs (che X-API-Key).

Nếu dùng LOCAL_FALLBACK, bổ sung ảnh docker compose ps và kết quả gọi API local.
Chưa có ảnh nghĩa là chưa có bằng chứng chạy; không dùng hình minh họa thay ảnh thật.
